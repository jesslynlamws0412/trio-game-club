# 复古桌游俱乐部（原“三人游戏俱乐部”）

支持单人、双人、三人、多人（4~8 人）联机的桌游平台，目前有 37 款可玩的游戏（其余在大厅里标为“开发中”）。双人模式还可以选择“本地轮流”：两个人共用一台设备。

线上地址：https://trio-game-club.onrender.com （免费托管，15 分钟没人访问会休眠，再打开要等约 1 分钟）

## 本地运行（Windows）

先安装依赖（只需一次）：

    npm install

### 方式一：开发模式（两个终端）

    npm run dev:server      # 终端 1：服务器，端口 3001
    npm run dev:client      # 终端 2：前端，打开 http://localhost:5173

### 方式二：单服务器模式（与上线后一致）

    npm run build
    npm start               # 打开 http://localhost:3001

同一局域网的手机可访问 `http://电脑IP:3001`。

## 测试

一键运行全部测试（自动启动临时服务器，约 5 分钟）：

    npm test

测试结果和覆盖范围见 `docs/测试报告.md`。单独运行某个测试需要先启动服务器，脚本都在 `server/test/`。
一个人想试玩多人游戏：先启动服务器，再运行 `node server/test/bots.mjs <游戏id>`，机器人会当另外的玩家。

## 数据

平台**不保存任何玩家数据**：没有账号、没有长期战绩、没有好友和成就。房间、房间内的积分榜和房间战绩只存在服务器内存里，房间关闭或服务器重启就没有了。
所以部署在免费托管上（休眠、重启、重新部署）不会丢失任何需要保留的东西。
唯一保存在玩家自己浏览器里的是昵称、头像和重连用的临时凭证。

## 题库

内置题库在 `server/src/bank/data/`，按题库分文件，格式见 `server/src/bank/build.ts`。游戏逻辑只通过 `server/src/bank/index.ts` 抽题和判题，加题不需要改游戏代码。题库中心可以在线浏览全部题目（带答案和解释）。
