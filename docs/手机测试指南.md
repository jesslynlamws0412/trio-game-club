# 用手机在家里测试（同一个 Wi-Fi）

目的：在发布到公网之前，先用你自己的手机检查一遍触屏操作（尤其是你画我猜的画板）。

## 步骤

1. **电脑上启动服务器**（在项目文件夹打开 PowerShell）：

   ```
   npm run build
   npm start
   ```

   看到“复古桌游俱乐部服务器已启动”就可以了。窗口不要关。

2. **第一次启动时 Windows 防火墙会弹窗**，询问是否允许 Node.js 访问网络。
   勾选“专用网络”，点“允许访问”。如果没弹窗、手机又打不开，见下面“常见问题”。

3. **确认手机和电脑连的是同一个 Wi-Fi。**

4. **手机浏览器打开**：`http://192.168.0.116:3001`
   （这是这台电脑目前的局域网地址。换了网络后地址会变，可以在 PowerShell 里运行 `ipconfig`，找“无线局域网适配器 WLAN”下面的 IPv4 地址。）

5. 手机建房、电脑浏览器输入房号加入，再找一个标签页或另一台设备当第三个人。
   也可以用机器人当对手：`node server/test/bots.mjs draw`（把 draw 换成别的游戏 id）。

## 重点检查清单

- [ ] 首页、大厅在手机上不用左右滑动就能看全
- [ ] 你画我猜：手指在画板上画线时，页面**不会跟着滚动**；颜色、粗细、橡皮、撤销、清空都能点到
- [ ] 画家在手机上画，另一端实时看到笔画
- [ ] 大富翁棋盘上的字能看清，掷骰子、购买按钮好点
- [ ] 切换到别的应用再回来 / 锁屏后解锁，能自动回到原来的房间和游戏
- [ ] 输入文字（昵称、描述、聊天）时，键盘弹出后输入框没有被挡住

## 常见问题

- **手机打不开页面**：多半是防火墙。电脑上以管理员身份打开 PowerShell，运行：
  `New-NetFirewallRule -DisplayName "TrioGameClub" -Direction Inbound -LocalPort 3001 -Protocol TCP -Action Allow`
  （这条命令只放行 3001 端口，用完可在“Windows Defender 防火墙 → 高级设置”里删除。）
- **手机能打开但一直“正在重连”**：检查是不是用了 `localhost`；手机上必须用电脑的局域网地址。
- **有些公司/学校/咖啡馆 Wi-Fi 会隔离设备**，这种网络下手机访问不到电脑，换成家里的 Wi-Fi 或用手机热点即可。
