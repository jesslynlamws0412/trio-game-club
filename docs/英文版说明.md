# 英文版说明（中文 / English）

右上角的“EN / 中文”按钮可以切换界面语言，选择记在这个浏览器里（第一次打开时，中文浏览器默认中文，其余默认英文）。
**每个玩家各选各的语言**：同一个房间里可以有人用中文、有人用英文，各自看到自己语言的界面和游戏提示。

## 现在哪些游戏有英文版

有完整英文版（规则、界面、游戏提示、错误提示）：
大富翁、UNO、叠叠高、保龄球、投篮机、羊了个羊、蛇梯棋、飞行棋、井字棋、五子棋、拼字游戏、记忆翻牌、吹牛骰子、猜数字、剪刀石头布、反应速度挑战（共 16 款）。

只有中文内容的游戏（题库问答、成语接龙、谁是卧底、你画我猜、狼人杀、海龟汤等）：
游戏名称和简介已经翻译，但游戏内容（题目、词语）是中文的，所以**房间里只要有一位玩家用英文，这些游戏就不能开始**，并会提示原因。游戏列表里用 “English” / “仅中文 (Chinese only)” 标签区分。

## 它是怎么工作的

- **界面文字**（客户端）：代码里写 `t('中文原文')`，英文放在 `client/src/locales/en.ts`。
- **服务器发来的文字**（游戏日志、错误提示、游戏名称和规则）：游戏引擎仍然直接生成中文，发给选了英文的玩家之前，由 `server/src/i18n.ts` 按词典 `server/src/i18n/en/*.ts` 翻译。带变量的句子用 `{a}` `{b}` 这样的模板。
- 找不到翻译的句子会原样显示中文，所以漏翻不会让游戏崩溃，只是那一句是中文。

## 以后怎么给一款游戏加英文版

1. 客户端组件里把所有中文界面文字包上 `t('…')`（变量用 `{名字}`），在 `client/src/locales/en.ts` 里写英文。
   运行 `node tools/i18n-keys.cjs list` 可以列出还没翻译的键。
2. 服务器引擎里的日志和错误提示：运行 `node tools/i18n-strings.cjs --missing server/src/games/某游戏.ts` 列出还没有翻译的句子，写进 `server/src/i18n/en/games.ts`。游戏的规则文字写进 `server/src/i18n/en/catalog.ts`。
3. 把游戏 id 加进 `server/src/i18n/en/catalog.ts` 里的 `EN_GAMES`。
4. 运行 `npm test`：测试里的“漏翻审计”会检查整套测试过程中这款游戏发出的所有文字，翻译成英文后还有中文就报错，并列出是哪些句子。

## 题库（问答类游戏）

题库的题目是中文内容（成语、古诗词、中国文学等），有些根本无法翻译。计划是：只给科学、世界地理、世界历史、趣味冷知识、日常常识、逻辑推理、影视音乐这几类写英文题目，
英文题目会放进同一个题库里，英文和中文玩家同房间时只抽两种语言都有的题。目前还没有做，所以问答类游戏仍是仅中文。
