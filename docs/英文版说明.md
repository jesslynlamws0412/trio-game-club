# 英文版说明（中文 / English）

右上角的“EN / 中文”按钮可以切换界面语言，选择记在这个浏览器里（第一次打开时，中文浏览器默认中文，其余默认英文）。
**每个玩家各选各的语言**：同一个房间里可以有人用中文、有人用英文，各自看到自己语言的界面和游戏提示。

## 现在哪些游戏有英文版

**27 款游戏有英文版**（游戏列表里带 “English” 标签）：

- 棋牌和动作类（16 款）：大富翁、UNO、叠叠高、保龄球、投篮机、羊了个羊、蛇梯棋、飞行棋、井字棋、五子棋、拼字游戏、记忆翻牌、吹牛骰子、猜数字、剪刀石头布、反应速度挑战。
- 题库问答类（11 款）：答题竞赛、常识问答、世界历史问答、世界文学问答、世界地理问答、科学知识问答、影视知识问答、音乐知识问答、趣味冷知识问答、逻辑推理、百万富翁。

**仅中文的游戏**（标 “仅中文 / Chinese only”）：成语接龙、谁是卧底、你画我猜、狼人杀、海龟汤、侦探推理、谁最有可能、默契大考验、真心话大冒险、禁忌词挑战、谁是说谎者、抽卡游戏，
以及中国历史、中国文学、中国文化、马华文学、成语、古诗词、脑筋急转弯这几个问答。它们的名称和简介已经翻译，但内容（题目、词语）是中文的，
所以**房间里只要有一位玩家用英文，这些游戏就不能开始**，并会提示原因。

## 英文题库

共 270 道题有英文版：科学（39）、世界地理（38）、世界历史（35）、世界文学（30）、影视音乐（39）、日常常识（32）、逻辑推理（29）、趣味冷知识（28）。
- 英文题和中文题是**同一道题**的两种说法（选项顺序、数量完全一样，所以答案不用改）。同一局里中文玩家看到中文、英文玩家看到英文。
- **房间里有英文玩家时，只会抽有英文版的题**；全是中文玩家时照常从整个题库抽。
- 填空题中英文答案都接受（例如“吉隆坡”和 “Kuala Lumpur” 都对）。
- 成语、古诗词、中国文学、马华文学、脑筋急转弯这类本身就是中文内容，没有翻译。
- 英文题是我翻译的，没有经过母语者审核。

## 它是怎么工作的

- **界面文字**（客户端）：代码里写 `t('中文原文')`，英文放在 `client/src/locales/en.ts`。
- **服务器发来的文字**（游戏日志、错误提示、游戏名称和规则）：游戏引擎仍然直接生成中文，发给选了英文的玩家之前，由 `server/src/i18n.ts` 按词典 `server/src/i18n/en/*.ts` 翻译。带变量的句子用 `{a}` `{b}` 这样的模板。
- **题库题目**：英文版放在 `server/src/bank/en/`（键是中文题干），服务器按每个玩家的语言分别发题。
- 找不到翻译的句子会原样显示中文，所以漏翻不会让游戏崩溃，只是那一句是中文。

## 以后怎么给一款游戏加英文版

1. 客户端组件里把所有中文界面文字包上 `t('…')`（变量用 `{名字}`），在 `client/src/locales/en.ts` 里写英文。
   运行 `node tools/i18n-keys.cjs list` 可以列出还没翻译的键。
2. 服务器引擎里的日志和错误提示：运行 `node tools/i18n-strings.cjs --missing server/src/games/某游戏.ts` 列出还没有翻译的句子，写进 `server/src/i18n/en/games.ts`。游戏的规则文字写进 `server/src/i18n/en/catalog.ts`。
3. 把游戏 id 加进 `server/src/i18n/en/catalog.ts` 里的 `EN_GAMES`（题库类游戏不用：英文题够多会自动算有英文版）。
4. 运行 `npm test`：测试里的“漏翻审计”会检查整套测试过程中这款游戏发出的所有文字，翻译成英文后还有中文就报错，并列出是哪些句子。

## 以后怎么增加英文题

在 `server/src/bank/en/` 对应的文件里加一条 `[中文题干, 英文题干, 英文选项, 英文解释]`（判断题选项写 `null`，填空题再加一个英文答案数组）。
中文题干必须和题库里的一模一样；英文选项的顺序和数量要和中文选项一一对应。`npm test` 会检查这些。
