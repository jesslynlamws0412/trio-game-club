# 测试报告

## 怎么重新跑一遍

在项目根目录运行：

```
npm test
```

它会自动启动全新的临时服务器（加速的计时器），依次运行所有测试，最后打印汇总表，约 6 分钟。
单独运行某个测试脚本前，要先启动服务器；为了让测试不用等 3 秒倒计时，需要设置 `START_COUNTDOWN_MS=0`（`flow.test.mjs` 例外，它需要 `START_COUNTDOWN_MS=500 IDLE_TURN_MS=700`）。

## 界面巡检（手动，用浏览器）

- 375 像素宽（手机）：23 个页面，以及单人 23 款、双人 19 款、三人 18 款游戏和 8 人房间 14 款游戏的游戏画面，都没有横向溢出。
- 768 和 1280 像素宽：23 个页面没有溢出。游戏画面只在手机宽度逐款检查过。
- 本地轮流：真实界面走过交接画面（剪刀石头布、吹牛骰子）和刷新页面后恢复。

## 已经移除的功能

战绩、游戏记录、成就、排行榜、好友和邀请、自定义题库、题目收藏、答题统计都已按要求移除，因为免费托管重启或重新部署后磁盘会清空，这些功能无法长期保存。现在平台不保存任何玩家数据；房间内的积分榜和房间战绩只存在内存里。

## 还存在的问题和限制

- 没有用多台真实设备、真实网络测过：所有联机测试都是脚本和浏览器模拟。反应速度挑战的成绩包含网络延迟。
- 声音和音效、复古像素风改造、设置页面没有做。
- 计划里的 66 款游戏已完成 29 款，其余在大厅里标“开发中”。
- 题库 503 题由我手写，**没有人工审核**；马华文学只有 22 题，成语接龙词库约 390 个成语。
- 超时自动行动只覆盖吹牛骰子、猜数字、记忆翻牌、真心话大冒险、抽卡、大富翁；谁是卧底、狼人杀、侦探推理、海龟汤没有（它们靠自由讨论或主持人，没有固定的“轮到谁”）。
- 五子棋棋盘在手机上每格只有约 20 像素，点起来比较小；电脑对手是简单规则 AI，会进攻和防守，但不是高手。
- 本地轮流只支持 9 款游戏，问答类没有加入（后答题的人时间会比先答的少）。
- 房间和进行中的游戏只存在服务器内存里，服务器重启后会消失。
- 房间号只有 4 位数字，没满的房间知道号码就能加入。
