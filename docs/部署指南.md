# 部署指南：把游戏放到网上，发网址给朋友

有两种办法，**都不花钱**。

| | 方案 A：临时公网网址（Cloudflare 快速隧道） | 方案 B：长期固定网址（Render 免费托管） |
|---|---|---|
| 要注册账号吗 | 不用 | 要（GitHub + Render，都免费） |
| 要装什么 | 一个小程序 cloudflared | Git |
| 网址 | 每次启动都不一样（xxxx.trycloudflare.com） | 固定（xxxx.onrender.com） |
| 你的电脑要开着吗 | **要**，关机/断网别人就进不来 | 不用 |
| 战绩是否保留 | 保留（存在你电脑上） | **会丢**：免费套餐重启、休眠或重新部署都会清空磁盘 |
| 适合 | 今晚就想和朋友玩 | 想长期放着，随时能玩 |

## 方案 A：Cloudflare 快速隧道

> 已在这台电脑上配置好：`C:\Users\你的用户名\trio-tools\cloudflared\cloudflared.exe`（官方版本，数字签名已验证）。
> **以后只需要双击项目里的 `start-public.bat`**，在弹出的“公网隧道”窗口里找 `https://xxxx.trycloudflare.com`，发给朋友即可。
> 下面是手动步骤，仅供了解原理。

1. 下载 `cloudflared`（Cloudflare 官方，Windows 版 `cloudflared-windows-amd64.exe`），
   放到一个文件夹，例如 `C:\tools\`。
2. 启动游戏服务器（项目文件夹里）：
   ```
   npm run build
   npm start
   ```
3. 另开一个 PowerShell 窗口，运行：
   ```
   C:\tools\cloudflared-windows-amd64.exe tunnel --url http://localhost:3001
   ```
4. 输出里会出现一行 `https://随机单词.trycloudflare.com`，这就是公网网址，发给朋友即可。
5. 两个窗口都不要关。关掉就等于下线。

注意：这个网址任何知道的人都能访问；只在玩的时候开着，玩完关掉。

## 方案 B：Render 免费托管

### 1. 一次性准备
1. 安装 Git：https://git-scm.com/download/win （一路下一步）。
2. 注册 GitHub 账号：https://github.com （免费）。
3. 注册 Render 账号：https://render.com ，选择“用 GitHub 登录”。

### 2. 把代码传到 GitHub
在项目文件夹打开 PowerShell：
```
git init
git add .
git commit -m "三人游戏俱乐部"
```
然后在 GitHub 网站新建一个**空仓库**（名字随意，可以选私有 Private），按页面提示执行它给出的两条命令
（`git remote add origin ...` 和 `git push -u origin main`）。

### 3. 在 Render 部署
1. Render 控制台 → New → **Blueprint** → 选你刚建的仓库。
   项目里的 `render.yaml` 已经写好所有设置，直接点 Apply。
   （也可以选 Web Service，手动填：Build Command = `npm install --include=dev && npm run build`，Start Command = `npm start`，Instance Type = Free。）
2. 等待 3~5 分钟，状态变成 Live，页面上方会显示网址 `https://xxx.onrender.com`。
3. 把这个网址发给朋友。

### 免费套餐的限制
- **15 分钟没人访问会休眠**，下次打开要等约 30~60 秒唤醒。约朋友玩之前，自己先打开一次网址。
- **休眠、重启或重新部署后，积分榜和战绩会被清空**（房间里正在进行的游戏也会丢）。
  想长期保存战绩，需要付费的持久磁盘或外部数据库——这需要你自己决定是否花钱，我不会擅自添加。
- 每月免费时长有限，但朋友局足够。

## 通用提醒
- 网址发给朋友就行，不需要他们安装任何东西，手机和电脑浏览器都能玩。
- 房间号只有 4 位数字，别人猜到房间号可以加入没满的房间；玩的时候把房间坐满 3 人就安全了。
- 不要把 `.env`、密码之类的东西传到 GitHub（本项目目前没有这类文件）。
